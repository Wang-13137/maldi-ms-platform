# 架构决策记录（ADR）

记录"当时为什么这么选"，以及**否决了什么**。代码只能说明结果，说明不了取舍；
半年后回看，最有价值的往往是"当初为什么不选另一条路"。

## 格式

每篇包含：背景 → 决策 → 理由 → 代价 → 否决的方案。新决策按顺序编号，
已采纳的不删不改，被推翻时新开一篇并在状态栏标"被 00xx 取代"。
